# TikTok Shop Order Processing Fee

Order Processing Fee is a fixed fee charged to all integrated Tokopedia sellers and TikTok Shop by Tokopedia sellers in Indonesia for successfully delivered orders.

The fee covers platform order processing work, including transaction processing, help center service handling, and new platform tools such as AI assistant features. The source also says the fee supports investment in shipping policy and platform logistics programs for sellers and customers.

## Effective Date and Amount

The fee applies from `2025-08-11 00:00 WIB`.

| Fee | Amount | Unit | Tax |
| --- | ---: | --- | --- |
| Order Processing Fee | `Rp1,250` | Per successfully delivered order | Tax inclusive |

The fee is per order, not per item. A single order with multiple products is still charged one `Rp1,250` Order Processing Fee.

## Charging Rule

The fee is deducted directly from order settlement after successful delivery.

```text
Order Processing Fee = Rp1,250 per successfully delivered order
```

The XLSX fee calculator includes this fee as a fixed `Rp1,250 per order` line in both before- and after-18 May fee simulations.

## New Seller Waiver

New sellers receive the first 50 orders free of Order Processing Fee.

The source says the waiver is provided as a one-time fee refund at each month end, unless another mechanism is separately announced to sellers.

## Refund Rules

Order Processing Fee is refundable only if the order has not been successfully delivered.

| Order State | Refund Treatment |
| --- | --- |
| Whole order refunded before successful delivery | Order Processing Fee is fully refunded. |
| Partial refund before successful delivery | Order Processing Fee is not refunded. |
| Return or refund after successful delivery | Order Processing Fee is not refunded. |

The partial-refund rule differs from item-based fees: because Order Processing Fee is charged per order, a partial refund before delivery does not return the fixed order-level fee.
